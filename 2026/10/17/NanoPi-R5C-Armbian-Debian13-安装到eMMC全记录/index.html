NanoPi R5C 安装 Armbian Debian 13 并迁移到 eMMC 全记录

发表于 2026-10-17 更新于 2026-10-18 分类于 硬件折腾 本文字数： 4k 阅读时长 ≈ 15 分钟
RK3568 小主机装 Armbian Debian 13 (trixie) Minimal：TF 卡引导、armbian-install 写入 eMMC、UUID 校验与验收，实测 1 分 22 秒装完，含故障对照表与 Maskrom 救砖。

目标板：FriendlyElec NanoPi R5C（RK3568B2 / 4GB LPDDR4X / 32GB eMMC / 双 2.5G 网口 / M.2 Key E）
镜像：Armbian Debian 13 (trixie) Minimal (CLI)，内核 6.18.56-current-rockchip64
方案：TF 卡启动 → armbian-install 写入 eMMC → 拔卡从 eMMC 启动
实际耗时：写卡约 4 分钟，首次启动约 1.5 分钟，写入 eMMC 1 分 22 秒，全程约 30 分钟

1. 环境与目标

1.1 硬件事实（决定方案的关键点）

项目 规格 对安装的影响
SoC Rockchip RK3568B2，4×Cortex-A55 主线内核支持良好
内存 4GB LPDDR4X —
存储 32GB eMMC + microSD 引导只能放 eMMC 或 SD
网口 2×2.5GbE（PCIe 挂载） 接口名叫 enP1p17s0 / enP2p33s0（非 lan1/wan1）
M.2 Key E，仅 PCIe 2.1 ×1 + USB 2.0 只能插 WiFi/BT 模块，不能插 NVMe SSD
启动限制 BootROM 不能从 USB / M.2 引导 引导必须落在 eMMC 或 TF 卡
电源 USB-C 5V 输入，建议 ≥2A 劣质电源是最大玄学故障源
调试口 3Pin 2.54mm，1500000 8N1 不是常见的 115200
按键 MASK（eMMC 刷机）+ User MASK 用于进 Maskrom

1.2 为什么分两步（TF → eMMC）

先让系统从 TF 卡跑起来，再用 armbian-install 把”引导 + 系统”整体搬到 eMMC，最后拔卡。这样全程可回退，TF 卡天然成为救援盘。

2. 准备清单

2.1 硬件

  • NanoPi R5C 主板（含 CNC 外壳）
  • USB-C 5V/≥2A 电源（必须能稳定输出 5V，避免 PD 诱骗不出电的快充头）
  • microSD 卡 8–32GB，Class10 / A1 以上，正品
  • USB 读卡器
  • 网线 ×1~2
  • 电脑（Windows）
  • USB-A 公对公数据线（仅救砖用，很多 A-A 线只有电源）
  • USB-TTL 串口线 3.3V（可选，强烈建议；波特率 1500000）
  • HDMI 线 + 显示器（可选）

2.2 软件（Windows）

工具 用途 备注
Armbian Imager 下载 + 校验 + 写卡一体 推荐，自动核对 SHA256
balenaEtcher 写卡 可直接吃 .img.xz
Rufus 写卡 必须选 DD 镜像模式
7-Zip 手动解压 不建议解压后再写，易损坏
RKDevTool + DriverAssistant 救砖 / Maskrom 从 FriendlyElec 网盘或 Radxa 文档获取
MobaXterm / PuTTY SSH 可选

⚠️ 用 Windows 自带解压 .xz 后用 Win32DiskImager 写卡，曾出现”解压损坏但工具不报错 → 烧完不启动”。要么交给 Etcher 直接吃 .xz，要么先核对哈希。

4. 阶段一 写入 TF 卡

  • Armbian Imager → 选 NanoPi R5C → Debian 13 (trixie) Minimal (CLI) → Flash

或手动：

  • Etcher 选择 .img.xz → Flash（Etcher 自行解压）
  • 或 Rufus → DD 镜像模式

写完后 Windows 提示”需要格式化” → 点取消（那是 Linux 分区表，正常现象）。

安全弹出读卡器。

5. 阶段二 首次从 TF 卡启动

  • 断开 R5C 电源
  • 插入 TF 卡
  • 接网线到任一 2.5G 口（两个口默认都发 DHCP 请求）
  • 插入 USB-C 5V 电源
  • 等待 1–2 分钟（首启自动扩分区 + 生成 SSH 密钥）

启动成功的标志：

指示灯 状态
SYS（红） 由常亮转为慢闪
网口灯 亮起 / 闪烁

有串口线时：3Pin 调试口，1500000 8N1，可看到完整启动日志。

6.2 首次登录

首次登录必须一次完成三步（中断需重来）：

  • 修改 root 密码（输入两遍）
  • 创建普通用户 + 密码（该用户拥有 sudo）

键盘为 QWERTY 布局；密码避免中文与特殊符号。

8. 阶段五 执行 armbian-install

当前 Armbian 中 armbian-install 已是 armbian-config 的 module_partitioner 模块的兼容入口，菜单文字与下面一致。

8.1 方式一：交互式（可看清每一屏）

屏幕 提示文字 选择
① What would you like to do? Install Armbian to a disk (SD / eMMC / NVMe / SATA / USB)
② Select the destination disk: mmcblk1 28.9GiB（eMMC，唯一一项）
③ Choose how /dev/mmcblk1 should boot: emmc — Full install to this device (boot + system)
④ Root filesystem for /dev/mmcblk1: ext4（Default, most compatible）
⑤ This will ERASE /dev/mmcblk1 and install Armbian (emmc, ext4). Proceed? Erase and install
⑥ Installing to /dev/mmcblk1 - please wait... 等待 1–8 分钟，勿断电
⑦ Installation to /dev/mmcblk1 finished successfully... 成功

操作键：方向键/Tab 移动，Enter 确认，Esc 取消（取消不会写盘）。
第 ③ 屏的另一个选项 sd 是”引导留在当前介质”，不要选。

8.2 方式二：一条命令（等价，避免点错）

参数说明：

参数 可选值 说明
--target /dev/mmcblkX 目标整盘设备，必须是块设备
--boot emmc sd mtd spi standalone uefi bios … emmc = 引导+系统都装到该盘
--fs ext4 btrfs f2fs 新手用 ext4；要快照可 btrfs
--yes — 不加会拒绝执行（安全设计）

10. 阶段七 切换到 eMMC 启动

  • 等红灯完全熄灭（约 5 秒，别只等屏幕黑）
  • 拔掉 TF 卡（本板 SD 优先级高于 eMMC，不拔会继续从卡启动）
  • 插电源上电

预期：3–10 秒出内核日志，SYS 慢闪，网口灯亮，30–60 秒可 SSH。
IP 可能变化，需重新在路由器里查一次。

12.2 网口重命名（可选，软路由建议）

问题：Armbian 板级 udev 规则写的是旧内核 PCI 地址 0001:01:00.0 / 0002:01:00.0，

功能不受影响，仅名字不同。

12.5 eMMC 寿命优化

  • /var/log 已挂 zram1（Armbian 默认日志内存化），无需额外操作
  • 大量写日志的服务，建议把数据目录放到 USB 硬盘
  • 定期查看寿命：sudo mmc extcsd read /dev/mmcblk1 | grep -i life

12.6 保留 TF 卡

不要格式化那张 TF 卡 —— 它就是救援盘：eMMC 系统起不来时插上照样能启动。

13. 故障对照表

现象 原因 解决
上电红灯常亮、不闪、无网络 电源不足 / 卡没插好 / 镜像写坏 换 5V/3A 好电源；重写卡并核对哈希
插卡后进的仍是原厂 FriendlyWrt eMMC 引导优先 Maskrom EraseAll 擦 eMMC
--api detect 目标为空 eMMC 未识别 重启一次；换卡排除；仍空则查硬件
armbian-install 命令不存在 缺 armbian-config sudo apt install -y armbian-config
Installation FAILED (code N) 设备/传输/工具错误 sudo tail -100 /var/log/armbian-install.log
装完拔卡黑屏/不启动 bootloader 未写成功 / 误选 sd 模式 插回 TF 卡 → sudo armbian-install bootloader --target /dev/mmcblk1 --yes
拔卡后还是老系统 未完全断电就插拔 完全断电 10 秒再上电
网口没拿到 IP 接口未重命名 / 线序 nmcli device status；换口试；sudo dhclient enP1p17s0
温度 80℃+ 被动散热、通风差 检查外壳装配；可加 5V 小风扇
SSH 提示 host key 变更 重装后密钥变化 ssh-keygen -R <IP>
armbianEnv.txt 与 fstab UUID 不一致 安装异常 手动同步两处 UUID

14. 救砖流程 Maskrom

适用：完全无法启动、--api detect 看不到 eMMC、需要彻底清空存储。

  1. 安装 DriverAssistant 驱动
  2. 板子断电
  3. 按住 MASK 键不放，插上电源，状态灯亮约 3 秒后松开
  4. 用 USB-A 公对公数据线连接电脑与靠 TF 卡那一侧的 USB 口
  5. 打开 RKDevTool，应显示 Found One MASKROM Device
  6. Advanced Function → Boot 选 MiniLoaderAll.bin（RK3568 版）→ 点 Download
  7. 勾选 EMMC → Switch Storage（板子有 SPI Flash 时必须先切存储）
  8. 点 EraseAll 清空 eMMC
  9. 之后插 TF 卡引导，或重新烧写镜像

原厂固件可从 FriendlyElec 网盘 获取（-eflasher- / -usb- 后缀版本）。
